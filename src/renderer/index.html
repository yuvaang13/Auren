auren — system guardrail

Welcome to Auren

A private, local-only guardrail for your AI agents.

Auren blocks websites, apps, and file access — at the OS level — until you unlock it with your fingerprint or passcode. 100% on-device. Zero telemetry.

Four guardrails: Network, Apps, File Isolation, and Sandbox Monitor — all in one sidebar.

Takes 5 seconds · No account required

Your policy, your machine

Pick a workspace folder to isolate agents. Everything outside it is denied by default — and .env, .ssh, keys, and browser stores are blocked even inside it.

Turning protection off requires biometrics — plus a 5-second cooldown — so an agent can't quietly disable it.

While protection is on, Auren also hides your keystrokes: this window can't be screen-captured, and interception is blocked.

You can add sites and apps anytime

        File System Guard Key Feature
        
              
        Local file-system isolation for AI agents. Default-deny — agents routed through Auren only see folders you explicitly mount. Sensitive files are always denied. This does not lock Finder / File Explorer itself — it gates agent file access (bridge, terminal gate, and path checks).
        
            
        
            Zero-knowledge
          
        

          
        
            
        
              
            
        
            
        
              Default-deny Virtual Mounts
              The agent starts with zero file access. Add one or more workspace directories below — only those folders are allowed through Auren's agent gates (bridge /v1/check/fs, terminal-command gate, and path checks). Everything else is refused before the read happens. Opening other folders directly in Finder / Explorer still works — those never pass through Auren. Mounts are stored locally in the encrypted store and — on macOS — as Security-Scoped Bookmarks.
            
        
            enforce
          
        

          
        
            
        
              
        
                
                
        Workspace directories
        
              
        
              
            
        

            
        
            
        
              
              No workspace mounted. Agents have no file access until you add a folder. Use Choose folder… to create a restricted Virtual Mount Point.
            
        
            
        
            
        On macOS, Auren requests a Security-Scoped Bookmark so the mount survives re-sandboxing. On Windows, the mount is enforced via explicit ACL containment. In both cases, the OS standard app-data directory stores the encrypted policy — never a remote database.
